# 모임기록

활동의 순간을 모아, 총회 보고를 간편하게.

제공된 `PRD.md`와 `Design (1).md`를 바탕으로 만든 HTML·CSS·JavaScript 웹사이트입니다. 외부 패키지, 회원가입, 서버 데이터베이스 없이 브라우저의 IndexedDB에 활동과 원본 사진을 저장합니다. 최초 실행 화면에는 실제 사용자 기록만 표시하며 예시 데이터는 넣지 않았습니다.

## 실행

Node.js가 설치된 Windows에서는 `start.cmd`를 실행하고 브라우저에서 **http://localhost:4173** 을 여세요.

터미널에서는 이 폴더로 이동한 뒤 다음 명령을 실행합니다. 별도의 `npm install`은 필요하지 않습니다.

```sh
node server.cjs
```

서버 종료는 `Ctrl+C`입니다. 소스는 정적 파일이므로 `index.html`, `styles.css`, `app.js`, `domain.js`를 일반 정적 웹 호스팅에도 올릴 수 있습니다. HTML 파일 직접 열기는 브라우저별 저장소 동작이 달라 로컬 서버 실행을 권장합니다.

**기록을 계속 사용하려면 같은 브라우저와 같은 주소를 사용하세요.** `localhost`와 `127.0.0.1`, 서로 다른 포트는 별도의 저장 공간입니다. 기록은 기기 간 동기화되지 않으며 브라우저 데이터 삭제 시 사라집니다. Node 서버는 파일만 제공하며 사진을 전송받거나 디스크에 저장하지 않습니다.

## 구현 기능

- 활동명·날짜·유형·안건·설명 등록 및 수정, 사진 없이 저장
- JPG·PNG 파일당 5MB, 활동당 20장 제한, 실제 이미지 읽기 검증
- 사진 묶음 업로드·미리보기·삭제, 오류 파일명 및 이유 안내
- 활동과 사진의 원자적 IndexedDB 저장, 새로고침 후 유지
- 활동명·안건·설명 검색, 기간·유형 동시 필터, 조회 버튼 적용
- 대표 사진 최대 3장, 선택 순서 보존, 첫 대표 사진을 표지로 사용
- 사진 확대 모달, Esc 닫기, 삭제 확인, 키보드 포커스 표시
- 기간 내 전체 활동을 날짜순으로 모은 서기 보고서
- 보고서 보완 후 복귀 시 제목·기간 유지 및 변경 사진 반영
- A4 인쇄 스타일, 보고 사진 원본 비율 유지, 브라우저 PDF 저장
- PC 3열·태블릿 2열·모바일 1열 활동 카드

보고 제목과 조회 조건은 현재 탭에서 화면을 오갈 때 유지됩니다. 활동 기록과 사진은 IndexedDB에 영구 저장되지만, 새로고침하면 보고 설정과 검색 조건은 초기화됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 기본 구조, 공통 모달 |
| `styles.css` | 문서 지정 색상·반응형 화면·인쇄 스타일 |
| `domain.js` | 입력 검증, 검색·정렬, 대표 사진 선택 규칙 |
| `app.js` | 화면 전환, IndexedDB, 사진 업로드, 보고서 |
| `server.cjs` | 내장 모듈만 사용하는 로컬 정적 서버 |
| `tests/domain.test.cjs` | 핵심 업무 규칙 자동 테스트 |

## 검증 명령

```sh
node --test tests/domain.test.cjs
node --check app.js
node --check domain.js
node --check server.cjs
```

## 사용 확인 순서

제작 시 자동 테스트 7개와 JavaScript 문법 검사를 통과했습니다. 실제 브라우저에서 필수값 오류, 사진 없는 활동 등록, 새로고침 후 유지, 보고서 생성, 상세 화면 왕복 후 보고 설정 유지, 모바일 너비에서 가로 넘침 없음도 확인했습니다. 사진 파일 선택 자동화는 브라우저 제어 도구의 연결 오류로 완료하지 못했으며, 실제 인쇄/PDF 출력도 추가 확인이 필요합니다. 아래 순서는 전체 기능을 직접 확인할 때 사용할 수 있습니다.

1. 활동을 사진 없이 등록하고 새로고침해 기록이 남아 있는지 확인합니다.
2. 수정에서 사진 4장을 넣고 상세 화면에서 대표 사진을 선택합니다. 4번째 선택은 차단되어야 합니다.
3. 대표 사진을 해제했다 다시 선택하여 순서와 목록 표지가 바뀌는지 확인합니다.
4. 검색어·기간·유형을 입력하고 조회하여 모든 조건이 함께 적용되는지 확인합니다.
5. 보고 제목과 기간을 넣고 대표 사진 없는 활동까지 포함되는지 확인합니다.
6. ‘사진 선택하러 가기’로 보완한 뒤 보고 화면으로 돌아와 반영 여부를 확인합니다.
7. ‘인쇄 / PDF 저장’에서 메뉴·편집 버튼이 제외되는지 확인합니다.

실제 출력의 여백·머리글·바닥글은 브라우저 인쇄 설정에서도 조정할 수 있습니다. 백업·복원, 로그인, 공동 편집, 클라우드 동기화, PPT·HWP 생성은 문서의 제외 범위에 따라 구현하지 않았습니다.
